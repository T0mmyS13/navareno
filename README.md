# 🟩 Navařeno – Finální verze aplikace

**Navařeno** je moderní webová aplikace pro správu a prohlížení receptů.  
Uživatelé mohou procházet recepty podle kategorií (např. předkrmy, hlavní jídla, dezerty), zobrazit detailní postupy, upravovat počet porcí a automaticky přepočítat množství ingrediencí.

Tato větev (`main`) obsahuje **finální podobu aplikace po testování a úpravách**.
